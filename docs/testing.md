# 测试方法与范围

技能加载、模型工具调用和 QQ 平台投递属于不同环节。本项目分别记录隔离测试与真实 QQ 私聊结果，不将登记成功或生成文件当作消息已发出。

## 隔离会话

[隔离测试结果](../verification/2026-11-08.json)覆盖三个独立的原生 Codex 会话：

| 场景 | 核对内容 |
| --- | --- |
| 提醒 | 读取实际时间，登记暂停的一次性提醒，查询、删除、再次查询，核对持久记录无残留 |
| 媒体分流 | 读取实际文件和适用技能，区分文件发送、后台生图与语音转换 |
| 日常聊天 | 普通闲聊不进入自检，不触发多余 QQ 工具操作 |

五个技能均经过格式检查和原生技能发现；报告中的文件摘要对应受测版本。隔离模式拒绝 QQ 外发，不运行付费生图，也不验证真实媒体上传或到期提醒投递。

## 真实 QQ 私聊

[私聊测试结果](../verification/qq-c2c-live-2026-11-08.json)覆盖从 QQ 客户端实际发起请求，到原生 Codex 处理、平台回执及客户端显示的链路：

| 场景 | 核对内容 | 结果 |
| --- | --- | --- |
| 日常聊天 | 自然回复，不续接自检话题，不额外调用工具 | 通过 |
| 文件 | 真实文件上传，取得平台回执，客户端显示文件 | 通过 |
| 语音 | 合成返回真实音频，再单独发送，取得语音回执，客户端显示语音 | 通过 |
| 一次性提醒 | 真实登记，到期主动投递，随后删除同一条测试提醒，核对无残留 | 通过 |

语音报告保留了一次上游连接失败及修复后通过的复测。它用于区分后端转换故障和 QQ 上传故障，不代表技能本身提供语音后端。

本次私聊未覆盖视频、图片投递、付费生图或所有周期提醒规则。平台回执也不表示用户已阅读、播放或确认收到。

## 在兼容服务上复验

[`verify_qq_codex_tencent_skills.mjs`](../verification/verify_qq_codex_tencent_skills.mjs) 面向已经部署同款 broker 和模型认证的服务器。它使用 `/etc/qq-codex/config.json` 及 `/opt/qq-codex/app/` 的部署约定，不是复制到任意 Codex 环境即可运行的通用测试器。

用 QQ 服务运行用户执行；`--stage` 指向包含本仓库 `skills/` 的绝对目录：

```sh
node verification/verify_qq_codex_tencent_skills.mjs \
  --stage "/absolute/path/to/qq-codex-skills"
```

脚本在服务的 diagnostics 目录建立独立工作区、独立 Codex Home 与临时会话。它通过现有模型认证完成真实模型调用，不读取 QQ 账号凭据；提醒仅以暂停状态登记，测试后清理。运行时会消耗所配置的模型额度。

## 公开记录

报告保留测试范围、工具名称、状态、时间和文件摘要，不包含密钥、实际服务地址、账号或群标识、私聊原文、媒体文件和原始平台回执。`gpt-image-2`、`qq_generate_image`、`tonso-blog-image2` 是模型、工具或技能名称，不是服务凭据。
